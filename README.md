# Safety-first GPS — User Comments A/B test

Open `home.html` using a local static server (e.g. `python3 -m http.server 8000`) and keep all files in the same folder.

**Demo only:** Four preset Singapore origin–destination pairs; schematic routes and illustrative times/distances, not validated pedestrian routes. Fictional reviews in `reviews-data.js` are explicitly marked **Sample User Review** and must not be represented as actual users or evidence. No external news/police/crime data is used in this variant.

**Not configured:** real place search (OneMap credentials), walkable routing geometry/API, community reviews API/database, moderation, geographic matching, live position and turn-by-turn guidance. The SOS flow is a confirmation and prototype notice only; no phone call is placed. Trusted contact is not configured. Demo review submission is local UI only, not published or persisted.

**A/B testing:** The five original HTML screens, navigation order, palette and core interactions are retained. Sample evidence supports only fictional demonstration scenarios, not real-world safety claims.
